# Treasure Chickens

Мод для Minecraft **1.21.1** (NeoForge), который добавляет куриц, несущих ценные предметы, прокачку, курятник и достижения.

## Возможности

- **11 видов сокровищных куриц** — от угольной до незеритовой, а также кварцевая, призмариновая, слаймовая, эндер-жемчужная и курица опыта (несёт сферы опыта вместо предмета).
- **Кормление** — накормите обычную курицу ценным предметом (ПКМ), и она превратится в соответствующую сокровищную.
- **Прокачка** — стильный интерфейс: уровень (1–10), стоимость апгрейда, характеристики (дроп, интервал).
- **Спец-способности** — на 5-м уровне курица кладёт предметы в 2 раза быстрее, на 10-м даёт двойной дроп.
- **Курятник** — блок с инвентарём (27 слотов): курицы в радиусе несут предметы прямо в него. Ставится входом к игроку.
- **Достижения** — дерево «Сокровищные курицы»: крафт, прокачка, сбор всех видов, курятник.
- **Спавн-яйца** — 11 окрасок, доступны в креативной вкладке «Яйца призыва», крафтятся через книгу рецептов.

## Установка

1. Установите [NeoForge для 1.21.1](https://projects.neoforged.net/neoforge).
2. Скачайте мод и положите `treasure_chickens-1.0.0.jar` в папку `mods`.
3. Запустите игру с профилем NeoForge 1.21.1.

## Разработка

Требуется Java 21. Сборка:

```
gradlew build
```

Готовый мод появляется в `build/libs/`.
